จุดกม.Cutoffเหลือสถานะ

เวลา Cutoff เป็นนาฬิกาจริง ตอนกดสตาร์ท ระบบจะนับจากเวลาที่กดจริง โดยคงช่วงห่างจากเวลาปล่อยตัวไว้เหมือนเดิม

กลุ่มวิ่ง · เห็นตำแหน่งเพื่อนแบบสด ไม่ต้องล็อกอิน
ตัวละครของคุณ (แสดงบนแผนที่และกราฟ)

ใครมีรหัสกลุ่มก็เห็นตำแหน่งของคนในกลุ่มได้ ส่งรหัสเฉพาะคนที่ไว้ใจ ทุกคนต้องใช้ไฟล์ GPX เดียวกัน และเปิด GPS ที่แท็บตั้งค่า ตำแหน่งส่งผ่านอินเทอร์เน็ต ถ้าไม่มีสัญญาณ เพื่อนจะเห็นตำแหน่งล่าสุดและเวลาที่เห็นล่าสุด พอสัญญาณกลับมาแอปส่งตำแหน่งปัจจุบันให้เอง

ตั้งค่า Firebase (ทำครั้งเดียวต่อกลุ่มเพื่อน)

1) สร้างโปรเจกต์ที่ console.firebase.google.com (แผนฟรี) 2) เมนู Build แล้วเลือก Realtime Database กด Create Database 3) แท็บ Rules วางกฎด้านล่างแล้วกด Publish (ถ้าเคยวางกฎรุ่นเก่าไว้ ให้วางใหม่ เพราะรุ่นนี้เพิ่มการแชร์เส้นทางให้โหมดผู้ชม) 4) คัดลอกที่อยู่ฐานข้อมูลมาใส่ช่องด้านบน หรือใส่ในไฟล์ config.js ให้เพื่อนใช้ร่วมกัน
